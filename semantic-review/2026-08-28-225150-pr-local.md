# Shared Personal Information for Seabase and MLC

The change replaces MLC’s duplicate applicant-information card with the common `PersonalInfoSection`. Seabase and MLC now import the same `STANDARD_PERSONAL_INFO_ROWS`, giving both pages one field-order, label, option, and layout contract. MLC retains its read-only controls and `From the selected seafarer profile` subtitle, while the deleted component has no remaining references.
